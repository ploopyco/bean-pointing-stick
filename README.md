# The Ploopy Bean Pointing Stick Mouse

![The Ploopy Bean Pointing Stick](https://cdn.ploopy.co/2026-04-08-bean-media-assets/bean-parallax-3.jpg)

By some stroke of luck, you've made your way here. The Ploopy Bean. Your life will never be the same.

This repository contains all of the design and production files necessary to make a Ploopy Bean. We've also included some kick-ass documentation on how to get it made, assemble it, and program it [which you can find here](https://ploopyco.github.io/bean-pointing-stick/).

What are you waiting for? Your new life awaits.

## QMK?!

Beans bought from the [Ploopy store](https://ploopy.co/shop/bean-pointing-stick/) come with QMK preloaded. [Check out the documentation](https://ploopyco.github.io/bean-pointing-stick/) for instructions on how to load new firmware onto your device. (It's super easy!)

The firmware file that ships with all Beans is included in this repository as well, as `firmwares/bean.uf2`.

In case you are new to the world of QMK, it is an open-source firmware for computer input peripherals. You can find the source code for all of our firmwares in [QMK's Github repository](https://github.com/qmk/qmk_firmware/tree/master/keyboards/ploopyco).

Note that you may have to look for specific development branches in order to find the source for all of our firmwares, as we frequently have pending pull requests.
